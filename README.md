# 漢字ぷよぷよ

同じ部首の漢字を上下左右に4つ以上つなげて消す、静的なブラウザーゲームです。

## 起動

`index.html` をブラウザーで開くだけで遊べます。ビルド・インストールは不要です。HTML / CSS / JavaScript の3ファイルをそのまま静的ホスティングに配置できます。Google Fonts に接続できない環境では端末の標準フォントで表示します。

ローカルサーバーを使う場合は、このディレクトリで `python3 -m http.server 8000` を実行し、 http://localhost:8000 を開きます。

## ルールと操作

- 6列12段の盤面に2つ組の漢字が落ちてきます。
- 同じ部首の漢字が上下左右に4つ以上つながると消えます。斜めは対象外です。
- 消去後に漢字が落ち、再び消えると連鎖になります。得点は消去数 × 10 × 2^(連鎖数−1) × 色の倍率です。
- 色の倍率は「1 + (100 − 色のヒント%) × 0.04」。色のヒント100%で1倍、50%で3倍、0%で5倍です。各消去の開始時点で倍率を決め、消去後に色が薄くなった分は次の消去から反映します。連鎖の途中でも倍率は更新されます。
- 20字消すごとに落下間隔が0.85秒から0.055秒ずつ短くなり、最短0.22秒になります。
- 10字消すごとに色のヒントが100%から10%ずつ薄くなり、100字で全種類が同じ背景色・枠色・文字色になります。文字や部首マークは読みやすい濃さを保ちます。盤面・落下中・次の組・部首一覧に共通で適用し、再スタートすると元の色に戻ります。
- 出現位置が埋まっている場合は、盤面上の2段の待機スペースから出現します。上端でも左右へ動かして空いている列へ逃がせます。
- 接地後は0.5秒の操作猶予があります。横移動・回転で接地したままの場合は猶予を延長しません。下キーで固定は早まらず、Spaceまたは「落とす」はすぐに固定します。盤面上にはみ出したまま固定されると終了します。
- ← / → で移動、↑ で時計回りに回転、↓ で落下、Space で一気に落下、P で一時停止します。
- 左右がふさがれて通常の回転ができない縦の2個は、回転を500ミリ秒以内に2回押すと上下の漢字を入れ替えられます。
- スマートフォンでは盤面下のボタンで操作します。
- ベストスコアをブラウザー内に保存します。
- 消去時に墨と金色の粒子、朱印風の掛け声、連鎖数、獲得点を表示します。掛け声は「気合→炎→氷嵐→増幅→呪縛→寿限無→大連鎖」の順で、7連鎖以降は「大連鎖」を繰り返します。連鎖に応じて演出が強くなり、5連鎖で最大になります。速度・得点・消去の待ち時間は変わりません。端末の「視差効果を減らす」設定時は粒子や揺れを省略します。

使用する部首は、さんずい・きへん・てへん・くちへん・くさかんむりの5種類です。各漢字の右下に部首を表示します。

## 検証

Node.js があれば `node --test tests/*.test.cjs` で消去・重力・連鎖判定、上端での左右移動と固定猶予を検証できます。
