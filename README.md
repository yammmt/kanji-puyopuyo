# 漢字ぷよぷよ

![漢字ぷよぷよのプレイ画面](docs/screenshot.png)

同じ部首の漢字を4つ以上つなげて消す、ぷよぷよ風のブラウザーゲームです。

← / → で移動、↑ で回転、↓ で落下、Space で一気に落とします。スマートフォンでは画面下のボタンで操作できます。詳しくはゲーム内の「遊び方」をどうぞ。

## 起動

`index.html` をブラウザーで開くだけで遊べます。ビルド・インストールは不要です。

ローカルサーバーを使う場合は、このディレクトリで `python3 -m http.server 8000` を実行し、[http://localhost:8000](http://localhost:8000) を開きます。

## 検証

Node.js があれば `node --test tests/*.test.cjs` で消去・重力・連鎖判定、上端での左右移動と固定猶予を検証できます。
